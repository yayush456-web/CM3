# Commando 3 – Android (touch)

Flash game running in a WebView through the bundled Ruffle 0.8.0 emulator.

## Controls
Left stick: move (up = jump, down = crouch). Right stick: aim, pushing it fires. GUN buttons switch weapon, JUMP button jumps. Android Back opens a pause/exit menu. The gamepad button cycles controls full / dim / hidden.

## Build the APK on GitHub
1. Upload everything in this folder (including the hidden .github folder) to a new repository.
2. Open the Actions tab, then Build APK, then Run workflow (it also runs on every push).
3. When it finishes, download the artifact Commando3-APK from the run page, unzip it and install app-debug.apk.

If a build fails, copy the red error lines from the log.
